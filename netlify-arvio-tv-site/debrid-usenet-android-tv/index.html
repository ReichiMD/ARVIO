How the connection works

The addon resolves; ARVIO presents and plays.

Bring a compatible integration

Configure an addon or service separately using an account and content access you are authorized to use.

Receive resolved sources

The integration returns compatible source metadata and a playable HTTP URL. ARVIO does not search Usenet or debrid infrastructure by itself.

Select or autoplay

Choose a specific result from the source page or let autoplay use the best ready candidate under the active preferences.

No account, addon or media is included

ARVIO does not provide debrid or Usenet subscriptions, source indexes, provider credentials, files or streams. It does not support direct P2P torrent or magnet playback. Users are responsible for choosing lawful services and accessing only content they are authorized to use.

Common questions

Debrid and Usenet FAQ

Does ARVIO include a debrid or Usenet account?

No. ARVIO does not include, sell or share provider accounts. You must separately configure a compatible addon or service you are authorized to use.

Does ARVIO play torrent or magnet links directly?

No. Raw P2P torrent and magnet playback is not supported. A compatible integration must return a resolved HTTP media source that the device can access.

What source information can ARVIO show?

When an addon supplies the metadata, ARVIO can show quality, file size, filename, language, addon attribution, provider labels and other source details before playback.
