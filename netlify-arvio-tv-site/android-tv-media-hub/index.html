ARVIO/Guides/Android TV media hub

Free Android app

Your media services, organized for Android TV.

ARVIO is a free, open-source media management hub for Android TV and Android. Optional ARVIO Web carries supported home servers, live TV, tracking and playback to iPhone, iPad, Windows, Mac, Chromebook, Apple TV and compatible smart-TV browsers.

One interface

Connect what you already use.

ARVIO does not replace your server or provider. It gives compatible services a consistent library, discovery and playback experience across profiles.

Jellyfin, Plex and Emby

Browse authorized libraries, recently added media and available media versions from supported home servers.

Trakt and Simkl

Bring watchlists, viewing progress, watched history and scrobbling into ARVIO, with control over which tracker powers each feature.

Live TV and guide

Use your own provider or playlist with categories, favorites, EPG data and catch-up metadata when the provider supports it.

Profiles and cloud settings

Keep separate profiles and synchronize supported configuration across devices through an ARVIO cloud account.

Subtitles and playback tools

Choose subtitle sources, configure playback preferences and optionally use supported AI subtitle tools with your own credentials.

TV, mobile and browser access

Use the free native app on Android TV and Android mobile, then add optional browser access on Apple devices, Windows, macOS, ChromeOS and supported smart TVs.

Setup

Start with the parts you need.

Install ARVIO

Create a profile

Choose the language, appearance and playback behavior for each person or shared viewing setup.

Connect authorized services

Add only servers, accounts, playlists and integrations you have permission to access.

Content boundary

ARVIO provides software, not content. It does not host, provide, sell, bundle or redistribute movies, shows, channels, playlists or streams. Playback availability and quality depend on your connected source, network and device capabilities.

Common questions

Android TV media hub FAQ

Is ARVIO free on Android TV?

Yes. The Android app is free and open source. ARVIO Web is a separate optional premium browser companion.

Does ARVIO include movies, shows or TV channels?

No. ARVIO is media management and playback software. You supply authorized servers, providers, files and integrations.

Which services can ARVIO organize?

ARVIO supports user-authorized Jellyfin, Plex and Emby servers, live TV providers or playlists, Trakt and Simkl tracking, subtitle tools and compatible personal integrations.
