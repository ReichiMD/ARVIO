Connection flow

Authorize, choose, synchronize.

Choose its role

Refresh the Library

ARVIO retrieves available lists and progress, then updates them as playback changes.

Sync is not media access

Trakt and Simkl store tracking metadata; they do not provide the playable file. A title in a watchlist or continue-watching row still requires a separate authorized server, provider, file or compatible integration for playback.

Common questions

Trakt and Simkl FAQ

Can Trakt and Simkl be connected at the same time?

Yes. ARVIO can keep both accounts connected and lets you select which service is active for supported lists, progress and tracking behavior.

Does ARVIO import a Simkl watchlist and continue-watching list?

ARVIO can load supported Simkl list and progress data into its Library and home experience after the account is authorized and synchronized.

Does playback mark items watched in both services?

When both trackers are enabled for sync, ARVIO can send supported playback progress and watched updates to each connected account. Network and service API availability still apply.
