Compatible Fire OS devices

Use ARVIO on Fire TV.

The Android TV build can be sideloaded on compatible Fire TV hardware, bringing ARVIO's remote-first library, tracking, live TV and player experience to supported Fire OS devices.

Before installing

Android compatibility with device-specific limits.

Fire OS is based on Android, but Fire TV models differ substantially in memory, codec support and system behavior. ARVIO keeps the same interface while playback capabilities follow the device.

TV remote navigation

The Android TV layout is designed around directional focus, select, back and player controls rather than touch input.

Official signed APK

GitHub releases use ARVIO's release signature so future official APKs can update an existing matching installation.

Home server support

Connect supported Jellyfin, Plex and Emby servers that the Fire TV can reach over the network.

Tracking and profiles

Use supported Trakt, Simkl and ARVIO cloud features in the same way as other compatible Android devices.

Hardware-dependent playback

4K, HDR, Dolby formats, subtitles and passthrough depend on the exact Fire TV model, connected display and audio chain.

Storage awareness

Lower-end sticks have tighter memory and storage constraints, especially for large guide data, cache and high-bitrate playback.

Install and test playback

More than Fire TV

ARVIO can run on compatible Fire OS hardware, but device capabilities vary. The optional ARVIO Web companion also provides browser access on iPhone, iPad, Windows, Mac, Chromebook, Apple TV and compatible smart TVs when a native Android installation is unavailable.

Common questions

Fire TV FAQ

Is ARVIO available in the Amazon Appstore?

ARVIO is distributed for Android through Google Play and as a signed APK on GitHub. Fire TV users may need to sideload the APK on a compatible device.

Will every Fire TV model support the same media formats?

No. Codec, HDR, audio passthrough, memory and performance support vary by Fire TV model and Fire OS version.

How are ARVIO updates installed on Fire TV?

A sideloaded installation can use a newer APK signed with the same ARVIO certificate. Obtain releases from the official ARVIO GitHub repository.
